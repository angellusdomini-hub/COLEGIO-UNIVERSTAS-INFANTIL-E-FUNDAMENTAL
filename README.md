# COLEGIO UNIVERSTAS - INFANTIL E FUNDAMENTAL

Repositorio de organizacao dos projetos do Colegio Universitas para Educacao Infantil e Ensino Fundamental.

## Estrutura

### atividades-infantis

- [1ano-atv1](https://github.com/angellusdomini-hub/1anoatv1) - atividade para 1º ano
- [jardim3-atv1](https://github.com/angellusdomini-hub/jardim3atv1) - atividade para Jardim 3
- [copa-2e3ano](https://github.com/angellusdomini-hub/2e3anocopa) - atividade da Copa para 2º e 3º ano
- [copa-4ano](https://github.com/angellusdomini-hub/4ano-copa) - atividade da Copa para 4º ano

### digitacao

- [2e3ano-digitar](https://github.com/angellusdomini-hub/2e3anodigitar) - atividade de digitacao para 2º e 3º ano
- [3e2ano-digitar](https://github.com/angellusdomini-hub/3e2anodigitar2) - atividade de digitacao
- [4ano-teste-digitacao](https://github.com/angellusdomini-hub/4anotestedigitacao) - teste de digitacao para 4º ano

## Observacao

Os codigos originais permanecem nos repositorios individuais. Este repositorio funciona como uma pasta central de organizacao para facilitar o acesso e a manutencao dos projetos.
