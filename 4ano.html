FASE 1 • ALGORITMOS

1. O que é um algoritmo?

Um algoritmo é uma sequência organizada de passos para realizar uma tarefa.

Imagine que você queira ensinar um robô a escovar os dentes. Ele não sabe fazer isso sozinho. Você precisa dar instruções claras e na ordem correta.

1. Pegar a escova → 2. Colocar pasta → 3. Escovar → 4. Enxaguar

Ideia principal: programar é dar instruções. Um algoritmo organiza essas instruções.

👨‍🏫 Momento do professor:
Pergunte aos alunos: “Que tarefa do dia a dia também precisa de passos em ordem?”
Sugestões: fazer um sanduíche, tomar banho, ligar o computador, entrar em um jogo.

✏️ Agora pratique

Exercício 1

Qual alternativa representa um algoritmo?

Exercício 2

Qual tarefa precisa de uma sequência organizada?

Exercício 3

Complete: ligar o computador → entrar no sistema → ________.

👨‍🏫 Fase concluída. Faça uma retomada rápida: “O que é algoritmo?” Depois avance.
FASE 2 • ORDEM DOS COMANDOS

2. A ordem dos comandos importa

O computador executa exatamente os comandos na ordem em que foram dados.

Veja este exemplo para entrar em um site:

1. Ligar o computador → 2. Entrar no sistema → 3. Abrir o navegador → 4. Digitar o endereço

Se tentarmos abrir o navegador antes de ligar o computador, a sequência não funciona.

👨‍🏫 Momento do professor:
Troque oralmente dois passos e pergunte: “O que daria errado?”

👨‍🏫 Fase concluída. Reforce: “Uma sequência errada produz um resultado errado.”
FASE 3 • MATRIZES E COORDENADAS

3. Matrizes e coordenadas

Uma matriz organiza espaços em linhas e colunas.

Cada espaço pode ser localizado por uma coordenada.

L2,C4 = Linha 2, Coluna 4

Sempre lemos primeiro a linha e depois a coluna.

👨‍🏫 Momento do professor:
Mostre exemplos oralmente: L1,C1; L3,C2; L5,C4.

✏️ Agora pratique

Exercício 1

Exercício 2

Em qual coordenada está o 🤖?

Exercício 3

O que significa L3,C5?

👨‍🏫 Fase concluída. Peça um exemplo: “Qual coordenada seria Linha 4, Coluna 3?”
FASE 4 • COMANDOS DE MOVIMENTO

4. Movendo o robô

Podemos programar um robô usando comandos de direção.

Exemplo: ➡️ ➡️ ⬆️ significa duas casas para a direita e uma para cima.

👨‍🏫 Momento do professor:
Faça uma sequência corporal com a turma: “1 passo para a direita, 1 para frente, 1 para a esquerda”.

✏️ Agora pratique

Exercício 1

O robô está em L3,C3. Qual comando o leva para L3,C4?

Exercício 2

O robô está em L4,C2 e precisa chegar em L2,C2. Qual sequência funciona?

Exercício 3 — Programe o robô

Leve 🤖 de L5,C1 até ⭐ em L1,C5.

Nenhum comando.
👨‍🏫 Fase concluída. Reforce que vários comandos juntos formam um algoritmo de movimento.
FASE 5 • REPETIÇÕES

5. Repetições

Quando um comando aparece várias vezes, podemos usar uma repetição.
➡️ ➡️ ➡️ ➡️ = REPITA 4 VEZES ➡️

Isso deixa o algoritmo menor e mais eficiente.

👨‍🏫 Momento do professor:
Diga “bater palmas 5 vezes” e compare com escrever “palma, palma, palma, palma, palma”.

✏️ Agora pratique

Exercício 1

Como representar ➡️ ➡️ ➡️ ➡️?

Exercício 2

Qual representa ⬆️ ⬆️ ⬆️ ➡️ ➡️?

Exercício 3

Para andar 6 casas para cima, qual é mais eficiente?

👨‍🏫 Fase concluída. Pergunte: “Por que usar REPITA economiza trabalho?”

6. Encontrando e corrigindo erros

Encontrar e corrigir um erro em um algoritmo chama-se depuração ou debugging.

Um erro em programação também pode ser chamado de bug 🐞.

Se deveria ser ➡️ ➡️ ⬇️ ➡️, mas aparece ➡️ ➡️ ⬆️ ➡️, precisamos encontrar o comando errado.
